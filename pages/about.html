ABOUT THE PROJECT

Building an end-to-end platform for Canadian economic intelligence.

Designed and developed by Mahin Chowdhury, this portfolio project combines cloud data engineering, economic analytics, business intelligence, forecasting, and interactive application design around official Canadian economic data.

Economic Sources 3 Official Sources
Integrated Data 10 Datasets
Serving Layer 12 Reporting Tables
BI Delivery 5 Report Pages

PROJECT OBJECTIVE

Make fragmented economic data easier to integrate, analyze, and communicate.

Canadian economic indicators are published across multiple institutions, formats, frequencies, and release schedules. The platform brings these sources into a governed analytical environment where data can be validated, standardized, aligned, modeled, and prepared for reporting.

The project demonstrates how an Azure-based data platform can support multiple delivery layers, including curated SQL reporting, Power BI dashboards, forecasting workflows, and interactive applications.

PROJECT SCOPE

The platform covers the full path from data ingestion to analytical delivery.

01

Cloud Data Ingestion

Official Canadian economic data is ingested through Azure Data Factory into the Bronze layer of ADLS Gen2.

02

Lakehouse Transformation

Azure Databricks notebooks validate, standardize, and transform data through Bronze, Silver, and Gold analytical layers.

03

Analytical Data Modeling

Gold analytical marts align economic indicators for macroeconomic, regional, industry, fiscal, affordability, and forecasting analysis.

04

SQL Serving Layer

Twelve curated reporting tables provide a stable interface between analytical processing and downstream reporting applications.

05

Business Intelligence

A five-page Power BI report presents executive, regional, industry, fiscal and affordability, and forecasting insights.

06

Forecasting & Interactive Application

Retail sales forecasting, Streamlit automation, an Azure Function API, and a grounded economic assistant extend the platform beyond descriptive reporting.
