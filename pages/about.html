ABOUT THE PROJECT

Building an end-to-end platform for Canadian economic intelligence.

This project combines cloud data engineering, economic analytics, business intelligence, forecasting, and interactive application design into a single portfolio platform built around official Canadian economic data.

Economic Sources 4+ Providers
Integrated Data 10 Datasets
Serving Layer 12 SQL Tables
BI Delivery 5 Report Pages

PROJECT OBJECTIVE

Make fragmented economic data easier to integrate, analyze, and communicate.

Canadian economic indicators are published across multiple institutions, formats, frequencies, and release schedules. The platform was designed to bring these sources into a governed analytical environment where they can be validated, standardized, aligned, modeled, and served for reporting.

The project also demonstrates how a modern Azure-based data platform can support multiple delivery layers, including SQL reporting, Power BI dashboards, forecasting workflows, and interactive applications.

PROJECT SCOPE

The platform covers the full path from data ingestion to analytical delivery.

01

Cloud Data Ingestion

Official economic data is ingested through Azure Data Factory into the Bronze layer of ADLS Gen2.

02

Lakehouse Transformation

Databricks notebooks validate, standardize, and transform data through Bronze, Silver, and Gold analytical layers.

03

Analytical Data Modeling

Gold datasets align economic indicators for macroeconomic, regional, industry, fiscal, affordability, and forecasting analysis.

04

SQL Serving Layer

Twelve reporting tables provide a stable interface between analytical processing and downstream reporting tools.

05

Business Intelligence

A five-page Power BI report presents executive, regional, industry, fiscal, affordability, and forecasting insights.

06

Forecasting & Application Layer

Retail sales forecasting and an interactive application layer extend the platform beyond descriptive reporting.
